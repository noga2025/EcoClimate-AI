دليل التشغيل

  1. فك ضغط ملف المشروع.
  2. افتح index.html باستخدام Chrome أو Edge.
  3. استخدم القائمة للتنقل بين الوحدات.
  4. جرّب الحاسبة والمحاكاة والتحدي والمساعد.
  5. للتعديل، يمكن فتح الملفات في Visual Studio Code أو أي محرر نصوص.

التقنيات المستخدمة

HTML + CSS + JavaScript — مع تصميم متجاوب واتجاه عربي RTL.

كل وحدة تؤدي وظيفة تعليمية أو تفاعلية واضحة: واجهة افتتاحية، أهداف، دليل تشغيل، وسائط وصور، تنقل بسيط، محاكاة، تحديات، وألوان متباينة وهادئة.

خريطة مطابقة معايير المسابقة

  • اسم واضح وفكرة جديدة: «مناخنا الرقمي».
  • دليل تشغيل: README + شاشة دليل التشغيل.
  • واجهة افتتاحية وأهداف واضحة.
  • سهولة التنقل وسرعة التحميل: ملفات محلية خفيفة دون مكتبات خارجية.
  • استخدام HTML/CSS/JavaScript: تقنيات قابلة للشرح للطالب.
  • وسائط وتفاعل دون إفراط: خريطة، مؤشرات، محاكاة، تحديات.
  • ألوان هادئة وتباين واضح وتصميم متجاوب.
  • زر خروج/تنقل واضح من خلال القائمة والعودة للرئيسية.
