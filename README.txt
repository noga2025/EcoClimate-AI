مناخنا الرقمي | EcoClimate AI — الإصدار التطويري V2
========================================================
هدف المشروع:
منصة تعليمية تفاعلية تربط التغيرات المناخية بالتكنولوجيا والمواد الدراسية.

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html في Google Chrome أو Microsoft Edge.
3) استخدم القائمة للتنقل.
4) جرّب الخريطة التعليمية، الحاسبة، المعمل، المحاكاة، التحدي والمساعد.

الملفات:
- index.html : واجهة المشروع.
- style.css  : التصميم والألوان والاستجابة للشاشات.
- script.js  : التفاعل والعمليات والمحاكاة.
- README.txt : دليل التشغيل.

التقنيات:
HTML5 + CSS3 + JavaScript.
لا يحتاج المشروع إلى تثبيت برنامج لتشغيله، ويمكن فتحه مباشرة من المتصفح.

ملاحظة:
مؤشر الكربون والمحاكاة والمساعد التعليمي نماذج تعليمية مبسطة وليست قياسات بيئية رسمية أو نظام ذكاء اصطناعي متخصص.

أفكار الإصدار التالي:
- إضافة بيانات مناخية حقيقية ومصادرها.
- حفظ نتائج الطالب.
- لوحة إنجازات وشهادة رقمية.
- تطوير مساعد AI فعلي مع توثيق مصدر الإجابات.
- إضافة شاشة خاصة بالمشروعات المصرية للتكيف والتخفيف.


الإصدار النهائي التجريبي:
- إضافة شاشة "مصر والتغيرات المناخية 2050".
- إضافة لوحة نتائج تعليمية.
- إضافة رحلة قرار: رصد → تحليل → حل → قياس أثر.
- تصميم المشروع بحيث يمكن شرحه للطلاب باستخدام HTML/CSS/JavaScript فقط.
- يمكن تطوير البيانات لاحقًا بمصادر موثقة، دون الادعاء بأن المؤشرات الحالية قياسات رسمية.


نسخة CHAMPION:
================
أضيفت تجربة "أنقذ مدينتك" كقلب ابتكاري للمشروع:
- الطالب يتولى دور صاحب القرار.
- توجد ميزانية افتراضية محدودة.
- يختار حلولًا مناخية مختلفة.
- كل حل له تكلفة وتأثير على الحرارة والمياه والانبعاثات.
- يمكن مقارنة مزيج الحلول وملاحظة النتيجة.
هذا السيناريو تعليمي ومحاكاة مبسطة وليس نموذجًا علميًا للتنبؤ.

قصة العرض أمام اللجنة:
1. افتح الشاشة الرئيسية.
2. وضّح أن المشكلة ليست نقص المعلومات بل تحويل المعرفة إلى قرار.
3. انتقل إلى "استكشف" لإظهار الربط بين البيئة والمواد الدراسية.
4. ادخل "أنقذ مدينتك" واجعل الطالب/المحكم يجرب قرارًا.
5. اعرض كيف تغيرت المؤشرات.
6. انتقل إلى "مصر 2050" لربط الفكرة بالإطار الوطني.
7. اختم بلوحة النتائج ودليل التشغيل.
